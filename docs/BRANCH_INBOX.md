## Procédure

1. Copier uniquement le résultat utile d'une branche ici.
2. Dédupliquer contre IDEA_LEDGER.md.
3. Contre-auditer les affirmations importantes.
4. Ajouter les preuves à EVIDENCE_LEDGER.md.
5. Ajouter/modifier l'idée dans IDEA_LEDGER.md.
6. Modifier MASTER_CONTROL.md uniquement si l'état courant change réellement.
7. Ajouter une entrée au changelog du Master Control.
8. Ne jamais supprimer une idée réfutée : conserver le motif.
