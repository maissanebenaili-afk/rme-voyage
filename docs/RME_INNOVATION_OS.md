# RME Innovation OS

## North Star
RME is a deterministic decision infrastructure for uncertain journeys, opportunities and transactions.

Core loop:

OBSERVE -> NORMALIZE -> PROVE -> SCORE -> DECIDE -> ACT -> MEASURE -> LEARN

## Product primitives
- Evidence Ledger: every important fact carries source, timestamp, confidence and state.
- Risk Graph: transport, hotel and multimodal edges become explicit graph nodes/edges.
- Opportunity Graph: grants, tenders, partners, affiliate offers and B2B leads use the same evidence model.
- Decision Capsule: compact machine-readable explanation of why an action is allowed, rejected or uncertain.
- Revenue Ledger: clicks, bookings, confirmations and commissions are separate states.
- Replay Engine: a decision can be rerun against frozen input and configuration to reproduce the result.

## Innovation rules
1. Unknown is never safe.
2. Assertions never become evidence.
3. LLMs may explain or generate hypotheses; deterministic engines own safety-critical calculations.
4. Every dynamic source has freshness and provenance.
5. No feature enters production without a measurable outcome.
6. Prefer reusable primitives over vertical-specific hacks.

## New moat
RME can evolve from Travel Intelligence into a general Decision OS. Travel is the first high-friction domain; the same graph/evidence/decision primitives can power MRE services, funding discovery, procurement opportunities and B2B sourcing.

## Experimental tracks
### 1. Counterfactual Travel
Generate safe alternatives: change hub, hotel, departure time or transport edge and calculate the delta in time/risk/cost.

### 2. Decision Replay
Store a redacted decision capsule so the same decision can be reproduced months later even if providers change.

### 3. Opportunity Radar
Apply the same evidence/risk/revenue machinery to grants, tenders, partner programs and business leads.

### 4. Friction Learning
Measure predicted transfer friction against observed outcomes without allowing the learning layer to silently change safety thresholds.

### 5. Revenue-aware Routing
Optimize for user utility while exposing commercial incentives separately; affiliate economics must never mutate safety/risk facts.

## Success metrics
- verified decisions / total decisions
- unknown facts surfaced before action
- false-safe rate
- decision replay success rate
- partner click -> booking -> commission conversion
- value generated per 1,000 decisions
- reusable-core ratio across products
