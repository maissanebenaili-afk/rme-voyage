# RME Route — Money Hunt / Opportunities

Last reviewed: 2026-09-26

## Purpose

Permanent business-development register for RME Route. Search continuously for legitimate opportunities that can:
- generate revenue;
- generate affiliate commissions;
- create strategic partnerships;
- reduce infrastructure, AI and API costs;
- provide grants, financing, credits or acceleration;
- create tourism-sector experiments, distribution or B2B opportunities.

Evidence rule: no opportunity is considered acquired or guaranteed until eligibility, current terms and acceptance are verified from an official source. If information conflicts, mark it UNVERIFIED.

## Priority

- P1 — Immediate: action now; high relevance and low/moderate effort.
- P2 — Prepare: worthwhile, but requires eligibility, dossier or technical preparation.
- P3 — Watch: potentially useful, but conditions or timing make immediate action inefficient.
- REJECT: outside scope, closed, insufficient evidence, or effort disproportionate to expected value.

# Non-negotiable verification rule

Before recommending an opportunity to Tarek as actionable:

Official source -> current conditions -> RME eligibility -> cost -> realistic economic upside -> deadline -> concrete next action.

Do not count:
- grants as cash until awarded;
- affiliate revenue until conversion occurs;
- cloud credits as revenue;
- theoretical maximums as expected gains;
- programmes with uncertain eligibility as confirmed opportunities.
